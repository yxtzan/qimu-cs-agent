- 实现与契约 / 文档的偏差：
  - 所有访客隔离、限流、模型预算保护、横幅均只在 `PUBLIC_DEMO=1` 生效。共享 KB 索引/向量缓存/模拟历史/评测数据不复制，读缓存按实际路径分隔；访客数据位于 `data/runtime/visitors/<sid>/`。卖家和看板合并共享模拟数据与当前访客真实数据。
  - 公开会话 ID 加访客后缀，避开现有 handoff 全局 token 的同名冲突；契约中的 ID 仍为 string。后台捕获 AsyncLocalStorage 访客和重置代次，排队键带命名空间；过期代次不再写入。
  - 只重置当前访客，跳过修改共享资源/清空其他访客摘要的全局钩子。共享模拟 trace 的误判修改也在公开模式禁用。
  - 全站额度落盘在 `data/runtime/public-demo-limits.json`；trace 增量高水位计费，transport 补足没有及时进入 trace 的外呼费用，取二者较大值防重复计费。reset、清 cookie、重启不能退款。实际北京时间零点重新计日，滚动小时计数跨零点保留。零点恢复使用脚本的注入时间验证，未实等跨夜。
  - 为保护现有大脑/LLM 目录，只在 store 入口安装针对 OpenRouter 的 fetch guard，并向既有 pipeline 注入 mock 分类器；未修改大脑/工具业务逻辑。范围说明见 [T22-1](../questions/T22-1.md)。
  - 顶部横幅由仅公开模式的 middleware 注入同源脚本，未修改前端组件。已实际检查顶部导航不被遮挡、手机底部导航未被挤出视口。
  - `npm run build` 改用 `next build --webpack`：当前环境默认 Turbopack 的 CSS helper 端口失败，webpack 能通过。Next 提示 middleware 命名将来迁移到 proxy；当前构建与运行成功，本任务不做迁移重构。
  - 为适配最新版 D014 的杭州 ECS **直连 80 端口**方案，公开 `npm start` 使用轻量 HTTP 入口读取 TCP peer，并覆盖/签名内部来源头，防伪造 IP 绕限流；非公开模式原样委托原 `next start` CLI。生产通过 `npm start` 启动，使用 `PORT=80` 即可。
  - 默认 `PUBLIC_DEMO_TRUST_PROXY=0`，与当前无反向代理方案一致。未来仅在可信代理追加 X-Forwarded-For 且入口仅供代理访问时设为 1。直接 `next dev` / `npx next start` 缺少可信 socket 入口，公开模式保守共用 `direct` IP 桶。
- 新增依赖：**无**。`tsx` 已存在于仓库；部署按文档使用完整 `npm ci`，不要省略 devDependencies，因为启动入口需要 tsx。
