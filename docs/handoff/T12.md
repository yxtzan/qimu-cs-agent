- 怎么验证（人类照着做就能看到效果）：
  1. `git checkout t12-chat-widget && npm install && npm run dev`。确认 `.env.local` 里没有 `NEXT_PUBLIC_USE_MOCK=0`（不设置或设为 1 就是 mock）。
  2. 第 1 步（尺码 + 洗护）：打开 http://localhost:3000/product/P002 → 点「问客服」→ 输入「我 160cm 50kg 穿什么码？这件能机洗吗」。应出现尺码卡片（推荐 M 码）、洗护回答和「参考了 2 条资料」折叠区。
  3. 第 2 步（查物流）：打开 http://localhost:3000/orders → 订单 QM2026100201 点「联系客服」→ 上下文栏显示该订单 → 输入「到哪了」。应出现物流时间线卡片。
  4. 第 3 步（确认卡片）：输入「上周买的那件外套换成 L，顺便看看有没有券」。应出现「请确认：申请换货」卡片，点「确认」后变为「已确认办理」+ 售后单号，并跟一张优惠券卡片。
  5. 第 4 步（转人工）：输入「衣服穿了全身起红疹，你们不处理我就去 12315 投诉」。应出现转人工提示，顶栏变为「等待人工接入」。
  6. 第 5 步（人工接入，单标签页模拟）：浏览器控制台运行 `__qimuMock.takeover()`，再 `__qimuMock.reply("您好，我是阿栖……")`，顶栏变为「人工客服 阿栖 为您服务」并在 2 秒内收到回复。`__qimuMock.release()` 交还 AI。
  7. 调试信息：点聊天窗顶部「🔍 调试」，再提问，AI 回复下方出现层级徽标行。
  8. 错误重试：输入含「模拟故障」的消息，出现错误气泡，点「重试」成功。
