# 交接记录目录

> 每完成一个任务，新建 `docs/handoff/T<编号>.md`，内容按下面模板写。**一个任务一个文件**，不要改别人的文件。
> 如果任务被打回重做，在同一个文件末尾追加「第 2 轮」小节。
> Claude（总指挥）靠这里了解进度，请写具体，不要写"已完成所有功能"这种话。

## 模板（复制使用）

```markdown
### T<编号> <任务名> — <Codex|Cursor> — <YYYY-MM-DD HH:mm>
- 分支 / PR：t05-brain-pipeline / #12
- 完成了：
  - …（逐条对应任务卡的验收标准，标 ✅ / ⚠️部分 / ❌未做）
- 怎么验证（人类照着做就能看到效果）：
  1. `npm run dev`，打开 http://localhost:3000/...
  2. 输入「…」，应看到 …
- 实际运行过的命令及结果摘要：
  - `npm run typecheck` ✅
  - `npm run eval` → 意图准确率 87%，L1/L2/L3/人工 = 22%/58%/14%/6%
- 与契约 / 文档的偏差：无 | …
- 新增依赖：无 | …
- 遗留问题 / 给下一个任务的提醒：…
```
