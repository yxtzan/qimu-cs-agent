  - `createConversation(buyerId, init?)` → `Conversation`（id 自动 `C1001…`；`init` 可覆盖任意字段，种子流量用）

  - `appendMessages(conversationId, NewMessage[])` → 补全 `id`（`C1001-M3`）/`createdAt` 的 `ChatMessage[]`。同时会自动更新会话 `updatedAt`、`lastMessagePreview`；**会话已是人工模式时**每条买家消息让 `unreadForSeller` +1。注意：触发转人工的那一轮，买家消息写入时会话还是 AI 模式，所以 T04 在转人工时自己写 `unreadForSeller: 原值 + 1`、`handoffAt`、`status: "waiting_human"`、`mode: "human"`。

  - `appendTrace(trace)` → `RouteTrace`（`id` 可省略，自动 `C1001-T2`）；**会自动把会话的 `lastLayer` 更新为这条 trace 的 layer**，T04 不用再改一次。建议顺序：买家消息 → `appendTrace` → 带 `traceId` 的 AI 消息。
  - `listTraces({ conversationId?, since?, includeSimulated? })`：`since` 含边界，按 `at` 升序；**`includeSimulated` 默认 true**（看板默认含模拟）。
  - 卖家操作也在这里：`takeoverConversation / replyAsSeller / releaseConversation / closeConversation / openConversationForSeller`，状态不允许时抛 `ConversationError`（NOT_FOUND 404 / CONFLICT 409）。
