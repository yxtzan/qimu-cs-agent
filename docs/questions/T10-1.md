### Q1 NEXT_PUBLIC_USE_MOCK 未设置时的默认行为 — Cursor — T10
- 类型：疑问
- 背景：CONTRACTS 写的是「`NEXT_PUBLIC_USE_MOCK=1` 时返回 mock」。但后端接口还没有，人类直接 `npm run dev` 时如果环境变量没设，商城会因为请求 `/api/*` 404 而一片空白；而 `.env.local` 不在版本库里，每个人都要手动加一行才能看到界面。
- 建议：后端（T04/T05）合并后，把默认值改回「未设置 = 走真实后端」；演示机上用 `.env.local` 明确写 `NEXT_PUBLIC_USE_MOCK=0` 或 `=1`。
- 临时方案（我现在怎么继续的）：`lib/api-client.ts` 里 `USE_MOCK = process.env.NEXT_PUBLIC_USE_MOCK !== "0"`——设为 `1` 或不设置都用 mock，只有显式设为 `0` 才走真实后端。后端就绪后只需改这一行（并在 `.env.example` 里加一行说明，该文件归 Codex，所以没动）。
