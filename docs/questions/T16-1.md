### Q1 重置钩子要在哪里被 import 才会生效 — Cursor — T16
- 类型：需要别人的目录改动（提示 Codex T03 / Cursor T17）
- 背景：`registerResetHook(name, fn)` 只有在注册它的模块被 import 过之后才生效。`POST /api/admin/reset` 和 `npm run seed` 是两个不同的入口（服务器进程 / 命令行进程），所以每个注册钩子的模块都要在这两处各 import 一次，否则网页上点「重置演示数据」时钩子不会跑。
- 建议：钩子的作者在自己的 PR 里补 import：
  - `app/api/admin/reset/route.ts`（已留注释位置）加一行 `import '@/lib/rag/<注册钩子的文件>'`
  - `scripts/seed.ts` 加一行同样的 import（T03 任务卡原本就允许改 seed.ts）
  - T17 的种子流量同理（`lib/analytics/gen-traffic.ts`，T17 是 Cursor，自己加）
  `app/api/admin/**` 属于 T16 特批给 Cursor，Codex 若要加这一行请在 PR 里说明，Claude 审查时视为允许。
- 另：`docs/CONTRACTS.md` §7 写着「由 Codex 在 T05 实现」，现在已由 Cursor 在 T16 实现，文字可顺手更新。
- 临时方案（我现在怎么继续的）：`resetDemoData()` 先只复制 seed → runtime 并执行已注册的钩子（目前没有）；`scripts/seed.ts` 里原有的 `buildKnowledgeIndex()` / `generateSeedTraffic()` 空函数保持原样。
