### Q1 项目文件被提交在 `qimu-cs-agent-starter/` 子目录，与“仓库根目录”约定不符 — Codex — T00
- 类型：规格矛盾
- 背景：AGENTS.md 和任务卡都假设 `docs/`、`lib/`、`package.json` 在仓库根目录。但仓库首次提交时，整个项目被放在 `qimu-cs-agent-starter/` 子目录下，`create-next-app` 的产物无法按任务卡放在根目录。
- 建议：保持项目在仓库根目录（现状）。后续如要再导入 starter 压缩包，请先在本地解压并把内容放到仓库根目录再提交。
- 临时方案（我现在怎么继续的）：用 `git mv` 把所有文件移到仓库根目录并提交到 `main`（提交 `Move project files to repo root`），文件内容没有任何改动；本地文件夹里原来的空目录 `qimu-cs-agent-starter/` 已删除。
