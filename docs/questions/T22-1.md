### T22 公开模式的范围内适配 — Codex — 2026-10-04
- 类型：规格实现边界与临时方案（无需停工）
- 背景：任务要求全站模型花费保护、顶部横幅、后台摘要不串号，但禁止改 `lib/llm/**`、大脑其他文件和前端组件。`handoff.ts` 的摘要 token 以 `cwd + conversationId` 为键，其重置钩子会清空全站 token。
- 范围内实现：公开模式会话 ID 加访客随机号后缀（契约中 ID 为 string），后台队列另外按访客 + 重置代次分键；访客重置跳过全局摘要/知识库/模拟流量/预热钩子，其他访客不会失效；后台回调绑定上下文与重置代次，旧代次不可写回。
- 模型保护：在 `lib/store` 的公开请求入口安装仅拦截 OpenRouter 地址的 fetch guard，每次外呼检查全站账本。trace 花费按增量入账，外呼响应 usage 用于补上摘要、预热、知识库试搜等没有及时进入 trace 的花费；两种累计取较大值，避免重复计费。不改全局环境变量。超过预算后注入现有 mock 分类器，外部调用立即拒绝，沿用现有模板/转人工兜底，并在聊天回复添加简化模式说明。
- 横幅：只在公开模式，由 Node middleware 给 HTML 注入同源 `/api/demo/banner` 脚本；脚本查询 `/api/demo/status` 并显示中文横幅。不修改 React 组件。HTML 使用本机 loopback 代理保留流式响应，RSC/API/静态资源照常处理。
- IP：Next Request 不提供 TCP peer 地址。默认不信任客户端 IP 头，统一使用保守的 direct 桶（400/日）；部署在 Caddy 后设置 `PUBLIC_DEMO_TRUST_PROXY=1`，使用其追加的 X-Forwarded-For 最后一项，避免客户端伪造前面的地址。Next 端口应只供可信代理访问。
- 预算语义：按北京时间实际日历日，超过后拒绝新外呼；已在途模型请求可能让最终账单略高于阈值，OpenRouter key 的 credit limit 仍是第三道保险。访客 reset/清 cookie/重启均不清每日额度账本。
- 任务卡明确要求验证脚本，因此新增 `scripts/check-visitors.ts`、后台验证脚本及 npm 入口；不会修改评测集、种子数据或已有前端 e2e。
