# 问题目录 — 给总指挥的问题 / 契约变更请求

> Agent 遇到契约不清、想改不属于自己的文件、发现规格矛盾时，新建 `docs/questions/T<编号>-<序号>.md`（例：`T04-1.md`），一个问题一个文件。**提完问题用临时方案继续干，不要停工。**
> Claude 会在同一文件末尾写「答复」并把状态改为「已答复」。

## 模板

```markdown
### Q<序号> <一句话标题> — <Codex|Cursor> — <任务编号>
- 类型：疑问 | 契约变更请求 | 规格矛盾 | 需要别人的目录改动
- 背景：…
- 建议：…
- 临时方案（我现在怎么继续的）：…
- 状态：待答复
```
